# Homepage guitar recordings

Quartertone's Yamaha Eterna is the selected homepage voice. This directory holds
24 prepared recordings: six strings, four strengths each. The loudest fifth tier
is omitted. The development lab imports the same bank and retains the three
alternatives in `src/lab/assets/guitar/`.

`quartertone.json` is generated by `pnpm samples:prepare`. It preserves source
pitches, offsets, and the reviewed whole-bank gain. Four equal MIDI velocity
bands cover the remaining layers. `audio/quartertone-bank.ts` resolves these
assets and applies the frets in `voicing.ts` without altering the files.

The homepage imports the bank and downloads its recordings only after explicit
sound activation. The other libraries are neither emitted in production nor
imported by the homepage. The sound defaults to off on every page visit.

Credit and processing details are in `QUARTERTONE-NOTICE.txt`; full license terms
are in `QUARTERTONE-CC-BY-4.0.txt`. The public privacy page also provides attribution.
The versioned source inventory is `scripts/guitar-sources/quartertone.json`.
